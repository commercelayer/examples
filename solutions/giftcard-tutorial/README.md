# Gift Card Tutorial

This is a Next.js app for buying gift cards. Users can select a gift card amount (preset or custom), choose a design, enter a recipient and message, and purchase the gift card.

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Run the development server:
   ```sh
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Features
- Select gift card amount (preset or custom)
- Choose a design
- Enter recipient and message
- Purchase button
